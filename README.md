# Kitty-clause

A competitive puzzle game created in only two days.

## About

A small runner game that I made as a New Year's Eve event.

At the beginning of the game, the player in the role of a cat reads letters from other cats, remembers their wishes and puts gifts in a bag. Moreover, the folding process itself is a separate mechanic: the player literally throws gifts with physics into a bag. After that, the Santa cat goes to deliver the gifts.

## Features
- My serious project on LeoECS
- New Year's Eve event
- Cute game
