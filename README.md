# Dize

A competitive puzzle game created in only two days.

## About

Dize is a local multiplayer strategy puzzle game where players place dice on their own columns while disrupting their opponent's board.

The goal is to score more points than your opponent using smart placement and combinations.

## Features

- Local multiplayer
- Strategic gameplay
- Score multipliers
- ECS architecture

## Technologies

- Unity
- C#
- LeoECS

## Development Challenge

This project was created in only two days as a personal challenge.
